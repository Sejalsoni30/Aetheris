Running at silky-smooth 60FPS with dynamic Three.js particle simulations, GSAP cinematic entry sequences, glassmorphic Bento grids, and live telemetry dashboards.

## ✨ Core Features

### 1. 🌌 Cinematic 3D Hero Section
- **Interactive Three.js WebGL Canvas**: 2,400+ Fibonacci-distributed glowing particles, inner geometric core, outer synaptic halo rings, and dynamic Plexus connections reacting to cursor parallax.
- **GSAP Staggered Entry**: Smooth fade-up cinematic typography with glowing gradient text fills.
- **Live Spatial Metrics Bar**: Global active nodes, 0.84ms raycast latency, and 8.4x attribution lift stats.

### 2. ⚡ Neural Core & Foveated Tracking HUD
- **Sub-Millisecond Coordinate Tracking**: Real-time vector calculations `[X, Y, Z]` as users navigate the spatial field.
- **Holographic Reticle Visualizer**: Rotating radar rings and synchronized crosshair lock.
- **Spatial Cohort Selectors**: Interactive testing across Luxury Spatial Commerce, Automotive XR, and Immersive Audio cohorts.

### 3. 🍱 Bento-Engineered Spatial Feature Grid
- **Neural Intent Mapping**: Live interactive waveform visualizer with real-time intent signal detection and sensitivity slider.
- **Spatial Campaign Builder**: Interactive 5-stage node pipeline (`Spatial Ingest` ➔ `Neural Vectorizer` ➔ `Intent Clustering` ➔ `Dynamic Placement` ➔ `Omni Conversion`).
- **Autonomous Conversion Agents**: Live animated status terminal with streaming optimization logs and verified lift stats.
- **Quantum Attribution**: Cross-reality multi-touch attribution breakdown across Apple Vision Pro, WebGL, and Spatial Audio channels.
- **Magic UI & Aceternity UI Styling**: Moving border beams, backdrop blurs (`backdrop-filter: blur-xl`), and mouse-follow spotlight illumination.

### 4. 📊 Live Spatial Telemetry Dashboard
- **Interactive Timeframe Switcher**: Instant metric recalculation across `24H`, `7D`, `30D`, and `ALL`.
- **Global Event Bus**: Live encrypted event stream receiving real-time intent evaluations from Tokyo, San Francisco, London, Berlin, Singapore, and Zurich.

### 5. 🎨 3D Shader Sandbox Drawer
- Dynamic floating drawer for customizing WebGL shaders and UI styles in real time:
  - **Chromatic Themes**: *Cyber Cyan*, *Deep Space Violet*, *Solar Gold*, and *Emerald Matrix*.
  - **Particle Density**: Adjust points from 800 up to 4,000.
  - **Rotation Velocity**: Control orbit speeds from 0.2x to 2.5x.
  - **Toggles**: Waveform turbulence, Plexus lines, and Web Audio synthesizer chimes.

### 6. 🚀 Spatial Simulator Console
- Interactive campaign simulator modal launched via the *"Launch Experience"* button.
- Choose audience cohorts, edge node deployment tiers, and simulate real-time spatial campaign launches with celebratory confetti explosions.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer, Custom Glassmorphism System
- **3D & Graphics**: Three.js (WebGL Particle Mesh & Plexus System)
- **Animations**: GSAP (GreenSock)
- **Sound Effects**: Native Web Audio API Synthesizer (No external assets required)
- **Icons**: Lucide React
- **Confetti**: Canvas Confetti

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v24)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Sejalsoni30/Aetheris.git

# Navigate into project directory
cd Aetheris

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
